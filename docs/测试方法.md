## 测试脚本

路径：`fastapi_backend/scripts/test_email_worker_lock.py`

在 `fastapi_backend` 目录下执行：

### 1. 只测锁，不发邮件（推荐先跑）

```bash
cd /path/to/fastapi_backend
python scripts/test_email_worker_lock.py --processes 4 --delay 5 --lock-only
```

等 5 秒后 4 个进程同时抢锁。正常应看到：
- 1 个 `OK lock acquired`
- 3 个 `SKIP lock not acquired`
- 最后 `RESULT: PASS`

### 2. 测锁 + 真发一封测试邮件

```bash
python scripts/test_email_worker_lock.py --to 你的邮箱@example.com --processes 4 --delay 5 --apply
```

4 个进程抢锁，**只有 1 个**会向你的邮箱发测试信。收件箱只应收到 **1 封**，主题带 `[OA lock test]`。

### 3. 模拟周排班多科室锁名

```bash
python scripts/test_email_worker_lock.py --lock-kind shift --departments 智能制造技术室,工艺技术室 --processes 4 --delay 5 --lock-only
```

### 4. 配合线上 4 worker 测真实 uvicorn

```bash
# 终端1：4 worker 启动（生产不要用 reload）
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# 终端2：连打两次待办提醒 API（有 GET_LOCK）
curl -X POST "http://127.0.0.1:8000/api/email/run-todo-reminder?current_user=admin1"
curl -X POST "http://127.0.0.1:8000/api/email/run-todo-reminder?current_user=admin1"
```

或在本机同时跑脚本 `--processes 4 --apply`。

## Ubuntu 改 4 worker 在哪改

仓库里 **没有** systemd 配置，worker 数在 **服务器启动命令** 里，常见位置如下。

### 第一步：找到启动命令

```bash
# 若是 systemd
systemctl status oa-backend
systemctl cat oa-backend | grep -E 'ExecStart|workers'

# 或搜所有可能的服务名
grep -r "uvicorn\|workers" /etc/systemd/system/ 2>/dev/null
grep -r "uvicorn\|workers" /etc/supervisor/conf.d/ 2>/dev/null

# 看当前进程
ps aux | grep uvicorn
```

### 第二步：改 `--workers`

在 `ExecStart` 里加上或改成 `--workers 4`，例如：

```ini
# /etc/systemd/system/oa-backend.service 示例
ExecStart=/path/to/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

**注意：**
- 生产环境 **不要** 加 `--reload`（reload 与多 worker 容易出问题）
- `python main.py` 默认单 worker，且 `DEBUG=True` 时会开 reload

改完后：

```bash
sudo systemctl daemon-reload
sudo systemctl restart oa-backend
ps aux | grep uvicorn   # 应看到 1 个 master + 4 个 worker
```

### 若是 supervisor

```ini
# /etc/supervisor/conf.d/oa-backend.conf
command=/path/to/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl restart oa-backend
```

### 连接池提醒

`config.py` 里 `MYSQL_POOL_SIZE=30`，4 worker 时总连接约 **30 × 4 = 120**。若 MySQL `max_connections` 偏小，需要调大或略降 `MYSQL_POOL_SIZE`。

---

**记忆口诀：** Ubuntu 上找 `systemctl cat <服务名>` 里的 `ExecStart`，改 `--workers 4`，然后 `daemon-reload` + `restart`。本地开发用 `python main.py` 永远是单 worker。
